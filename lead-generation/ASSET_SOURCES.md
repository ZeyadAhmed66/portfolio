# Tool icon sources

Logos identify tools in the supplied backend workflow, not partnerships.

- n8n, Google Sheets, Google Gemini, Railway: Simple Icons source repository (https://github.com/simple-icons/simple-icons), develop/icons SVGs. Single-color marks use brand colors on neutral backgrounds.
- Apify: official brand symbol, https://apify.com/img/brand/apify-symbol.svg, listed at https://apify.com/resources/brand.
- Apollo.io, MillionVerifier: public SVG assets retrieved from https://logoapi.sh/icon/apollo.io.svg, https://logoapi.sh/icon/millionverifier.com.svg.
- Bright Data: official white logo from https://brightdata.com/static/media-center/logos.zip, listed in https://brightdata.com/media-center.

Workflow explanations are a grouped illustration of the supplied 134-node n8n export. The source JSON, credentials, node IDs, account references, endpoints and company/client records are not included. No live workflow or API is run by this site.
